## 4. Стек технологий
*Back* Python 3.11+, пакеты `FastAPI`, `NetworkX` (полный список в `requirements.txt`).
**Front** JavaScript, Vite, CSS3, HTML5.

## 5. Инструкция по развертыванию и запуску

Для работы приложения необходимо запустить обе части проекта в раздельных терминалах.

### Backend
```bash
cd backend
python -m venv venv
# Для Windows:
venv\Scripts\activate

pip install -r requirements.txt
python main.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Запуск unit-тестов
Для проверки корректности работы графовых алгоритмов и API выполните в папке `backend`:
```bash
pytest
```

## 6. Ограничения и допущения
* Модель района, параметры дорожной сети и численность населения являются полностью условными.
* Прототип носит демонстрационный характер и не предназначен для официальной градостроительной экспертизы.
